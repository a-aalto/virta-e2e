# Virta E2E

An end-to-end data pipeline for collecting and processing electricity market data from Nord Pool and ENTSO-E. This project extracts and transforms data, then loads it into SQLite for further analysis and querying.

### Current data source for the pipeline

Nord Pool / ENTSO-E Transparency Platform via Volton, CC-BY-4.0. CC-BY-4.0.

Volton Technology OÜ (2026). Finland day-ahead spot price.
CC-BY-4.0. https://public-data.volton.energy/day-ahead-spot-fi/
